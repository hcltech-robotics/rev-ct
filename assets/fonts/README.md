# Font sources

The unmodified variable font and SIL Open Font License were downloaded from the official Google Fonts repository on 2026-10-11.

- Font: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf
- Licence: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt

- Font: https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexmono/IBMPlexMono-Regular.ttf
- Licence: https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexmono/OFL.txt

The plotting script instantiates weights 400 and 600 in a temporary directory. SVG text is converted to paths and PDF fonts are embedded so exported figures preserve Manrope without a network request.
